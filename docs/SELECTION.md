# 사건 묶기 · 관련 이슈 · 주요 뉴스 선정 규칙 (3단계)

코드: `scripts/build_news.py` 의 `cluster_detail`, `link_issues`, `story_target`, `pick_representative`,
`assign_story_ids`, `select_top`, `compose`. 비교 도구: `tools/compare_selection.py`.

## 1. 같은 사건 (story)

제목을 한글 2글자 단위·영단어로 나눠 IDF 가중 유사도(임계값 0.45)로 비교합니다. 각 사건의 첫 기사(seed)와 직접 비교합니다.

- **시간 폭**: 사건의 최초 기사 ~ 최종 기사가 **24시간**을 넘지 않습니다. 기준은 최초 기사 시각으로 고정되어 최신 기사가 들어와도 움직이지 않습니다.
  넘는 후속 보도는 새 사건이 되고 `follow_of` 로 기록되어 **같은 이슈로 연결**됩니다.
- **의미 충돌이면 합치지 않음** (seed 와 가장 최근 기사 둘 다와 검사, 애매하면 분리):

  | 충돌 | 예 |
  |---|---|
  | 문두 주어(쉼표 앞)가 서로 다른 기업·인물·기관이고, 상대 제목에 내 주어가 없음 | "DB증권, 3분기…" / "오리온, 3분기…" |
  | 날짜(N일)가 다름 | "19일 선고" / "17일 회담" |
  | 반대 방향 표현 | 인상/인하, 가결/부결, 상승/하락 |

  같은 대상의 다른 표기(李대통령·이 대통령·李, 호환 한자 포함)와, 조사·제재 기관이 주어인 경우(정부·공정위·검찰 등)는 충돌로 보지 않습니다.
  금액·비율 비교는 반올림 표기("4.86%"/"4.8%")와 서로 다른 수치 때문에 같은 사건을 더 많이 갈라놓아 쓰지 않습니다.

## 2. 관련 이슈 (issue)

같은 사건보다 한 단계 넓은 묶음입니다. 예: "수능 와이파이 차단"과 "범정부 대응팀 구성"은 **각각의 사건**이지만 같은 이슈입니다.

- 사건마다 낱말 묶음(첫 기사 제목 + 구성 기사 2개 이상에 나온 낱말, 흔한 낱말 제외)을 만들고,
  두 사건이 공유하는 희귀 낱말 3개 이상·IDF 합 **13 이상**이면 연결 후보입니다. 시간 간격은 72시간 이내.
- 강한 연결부터 잇되 이슈 크기가 **20**(2곳 이상 보도 사건 1, 1곳 보도 0.25)을 넘으면 잇지 않습니다.
- 1곳만 보도한 사건은 한 이슈에 붙을 수는 있지만 **두 이슈를 잇는 다리가 될 수 없습니다.**
- 이슈 ID 는 이슈 안에서 가장 먼저 생긴 사건의 ID 에서 만듭니다.

## 3. 사건 ID

사건 ID(`s_…`)는 대표 기사 ID 와 별개이며, 대장 `data/state/story_registry.json`(기사 ID → 사건 ID)으로 실행 간에 이어집니다.

| 경우 | 처리 |
|---|---|
| 대표 기사가 바뀜 | ID 유지 (기사 구성으로 판단) |
| 이전 사건 여러 개가 한 묶음으로 합쳐짐 | 가장 많은 기사가 속했던 ID 유지(동수면 먼저 생긴 것), 나머지는 `lineage.merged_from`, 대장에 `merged_into` |
| 이전 사건 하나가 여러 묶음으로 나뉨 | 가장 많이 가져간 묶음이 ID 유지, 나머지는 새 ID + `lineage.split_from` |
| 처음 보는 묶음 | 최초 기사에서 만든 새 ID |
| 캐시 유실 | 배포된 `news.json` 의 기사→사건 대응으로 복구 (상위 600건 + 과학 150건 범위) |

## 4. 언론사 소재와 사건 대상 지역

| 필드 | 뜻 |
|---|---|
| `source_region` | 보도한 언론사 소재: `kr` / `intl` / `mixed` |
| `target_region` | 사건이 일어난 곳·당사자: `kr` / `intl` / `both` |
| `target_basis` | 판단 근거: `korea_signal`, `foreign_signal`, `foreign+korea_signal`, `world_feed`, `feed_northkorea`, `outlet_intl`, `outlet_fallback`, `mixed` |
| `region` | 주요 뉴스 할당 구분: `target_region` 이 `intl` 이면 intl, 그 밖(kr·both)은 kr |

기사 판정 (제목만 사용. RSS 요약 첫머리의 "(마닐라=연합뉴스)" 같은 취재지는 국내 사안도 해외로 보이게 해서 쓰지 않음):

- 국내 언론: 기본 kr. 해외 신호(국가·정상·국제기구 이름, 美·中·日·러 약어)만 있으면 intl, 한국 신호(한국·韓·李·북한·국내 기업·K- 등)와 함께 있으면 both.
  국제 섹션 기사는 기본 intl, 한국 신호가 있으면 both. 북한 섹션은 kr(한반도 사안).
- 해외 언론: 기본 intl. 한국 신호가 있으면 kr (해외 언론이 본 한국 사건).
- 신호가 하나도 없으면 언론사 소재로 정하고 `outlet_fallback` 으로 표시 (**분류 불확실**).

사건 판정: 구성 기사 다수결. 국내·해외 판정이 각각 1/3 이상 섞이면 `both`.

**주요 뉴스 60:40 은 사건 대상 기준**입니다. 국내 할당 = kr + both(한국이 당사자인 공동 사건), 해외 할당 = intl.
화면의 국내 탭은 kr·both, 해외 탭은 intl·both 를 보여 주므로 공동 사건은 두 탭에 모두 나옵니다.
분류 불확실(`outlet_fallback`)은 할당 계산에서 언론사 소재를 따릅니다.

## 5. 대표 기사

카드의 제목·링크·언론사·시각은 대표 기사 하나에서 옵니다. 점수 = 0.35×시각 신뢰도 + 0.4×내용 완결성 + 0.25×새 전개 반영.

| 구분 | 재료 | 성격 |
|---|---|---|
| 시각 신뢰도 | `published` 1.0, `dc:date` 0.9, `updated_only` 0.6, `legacy` 0.5, 미상 0 | 관측 |
| 완결성 | RSS 요약 길이(120자에서 만점), 직접 수집 링크 여부 | 관측 |
| 완결성 보정 | 제목의 (종합)/(N보) +, [속보]/[포토] − | **추정** (`rep_basis.estimated` 에 문구로 남김) |
| 새 전개 | 사건의 최신 기사와의 시간 차 (6시간 반감) | 관측 |

언론사 고정 순위는 점수가 같을 때만 쓰는 마지막 기준입니다. 제목·RSS 정보만으로는 독립 취재 여부나 기사 품질을 판정할 수 없으며, 이 점수는 그런 판정이 아닙니다.

## 6. 주요 뉴스 선정

- 할당: 40건 = 국내 24 + 해외 16 (사건 대상 기준). 점수 공식은 2단계와 같습니다.
- **분야 상한**: 할당 × 40% 의 **내림** (국내 9, 해외 6). 상한을 넘겨 채우지 않습니다.
  예외: 해외 할당의 '국제'(world) 분류. 해외 기사는 거의 모두 이 분류라 상한을 걸면 후보가 사라집니다.
- **이슈 상한**: 같은 이슈는 국내·해외 합쳐 **2칸**까지. 나머지 관련 사건은 카드의 "관련 사건 N건"에서 볼 수 있습니다.
- 후보가 모자라면 적게 고르고 `news.json` 의 `selection` 에 할당·선정 수·건너뛴 사유(`category_cap:*`, `issue_cap`)·부족 사유를 남깁니다. 화면 상단 안내에도 표시됩니다.
- 주요 뉴스로 뽑힌 사건은 공개 목록(`news`) 600건 제한과 관계없이 항상 포함합니다.

## 7. 알려진 한계 (2026-11-16 표본)

- **동명이인**: 제목만으로는 같은 이름의 다른 사람을 구분할 수 없습니다. 예: 방송인 최동석의 소송과 인사처장 최동석의 판결이
  관련 이슈로 연결됨. 연결 기준을 높이면 "수능 와이파이 차단 ↔ 범정부 대응팀" 같은 실제 관련 사건도 끊어져 그대로 둡니다.
- **표현이 크게 다른 같은 사건**: "사상 첫 미중러 정상회담…" 과 "중국, 19일 시진핑·트럼프·푸틴 정상회담 개최 공식 발표" 는
  같은 사건이지만 별개 사건으로 남아 주요 뉴스 두 칸을 차지할 수 있습니다.
- **영어 제목의 일반 낱말**: "Men's / Women's college basketball" 처럼 일반 낱말이 많은 영어 제목은 서로 다른 기사가 묶일 수 있습니다.
- **대상 지역 오분류**: "옥스퍼드대 K문학 출판"(한국 관련인데 해외로), "국제선 유류할증료…뉴욕 왕복"(국내 사안인데 공동으로) 등.
  신호 낱말 목록 기반이라 완전하지 않으며, 신호가 없으면 `outlet_fallback` 으로 표시됩니다.
