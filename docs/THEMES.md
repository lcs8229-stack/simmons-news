# 테마 탭

편집 설정에 정한 **주제**와 기사 관련도를 기준으로 **주제 기사 6건 + 시야 넓히기 4건**(기본값)을 고릅니다. 규칙 기반이며 API 키가 필요 없습니다.

- 편집 설정: [`config/themes.json`](../config/themes.json) — 주제 목록·관련 개념·감점 기준·선정 비율·다양성 상한·출처 등급을 **이 파일 한곳**에서 고칩니다.
  둘 수 있는 최상위 항목은 `scripts/theme.py` 의 `ALLOWED_CONFIG_KEYS` 이며, 그 밖의 항목은 읽을 때 버립니다.
- 코드: `scripts/theme.py` (판단·보관·선정), `scripts/build_news.py` 의 `build_theme` (실행 연결), 결과 `data/theme.json`.
- 정치 성향 판단에는 쓰지 않습니다. 언론사 성향(lean) 값은 테마 선정에 쓰지 않습니다.
- 주제에 속한 기술·자산에 대한 **비판·위험 분석도 주제 기사**입니다. 특정 방향의 의견을 우대하지 않으며, 비판·위험 표기는 '글의 성격' 신호로 셉니다.

| 기술·철학 | AI 윤리, 기술과 사회, 철학, 논쟁·성찰 |

## 판단 항목 (따로 계산)

| 항목 | 방법 | 비고 |
|---|---|---|
| 관련도 | 주제마다 **개념**(낱말 묶음) 단위로 센다. strong 개념 1개 이상 + 서로 다른 개념 2개 이상 + 가중치 합 1.5 이상일 때만 관련 | 낱말 한 번 등장만으로는 선정되지 않음. 같은 계열 개념(AI 산업·AI 일반)은 하나로 셈. 주제 전문 매체(예: 이더리움 재단)는 개념 1개로 셈 |
| 분야 연결 | 2개 이상 주제에 관련이면 가산 | 예: AI 투자 × 금융 위험 |
| 글의 성격 | 제목·RSS 요약의 분석·질문·비판·근거 표기 | **관측된 표기**일 뿐 실제 깊이를 확정하지 않음. 요약이 짧고 표기도 없으면 `판단 불가`(중립값) |
| 출처 | 연구기관 1.0 · 전문지 0.85 · 일반 언론 0.55 · Google 뉴스 경유 0.4 | 출처 성격 분류이며 개별 기사 품질 판정이 아님 |
| 최신성 | 발행일 기준 반감기 10일, 최근 28일만 | 발행일 없는 글은 후보가 아님 |
| 감점 | 주가 등락·가격 전망·홍보/협찬·자극적 제목·속보 표기·목록형(뉴스레터 번호 등) | 점수에 곱함 |
| 중복 | 같은 사건 묶음, 같은 제목 재게시, 이미 고른 글과 제목이 매우 비슷한 글(사설·후속) | 한 건만 |

점수: 주제 기사 = 0.40×관련도 + 0.25×성격 + 0.20×출처 + 0.15×최신성 (+연결 가산) × 감점, 기준 0.56 이상.
시야 넓히기 = 0.45×성격 + 0.35×출처 + 0.20×최신성 × 감점, 기준 0.62 이상, 설정된 주제와 관련도가 낮고 분석·질문 표기가 있는 글.

## 선정

1. 주제 기사: 먼저 **주제마다 가장 좋은 글 1건**(주제 최고 점수 순), 남은 자리는 점수 순. 한 주제 최대 2건.
2. 시야 넓히기: 분야(과학·경제·문화·국제 …)마다 최대 1건.
3. 전체: 한 매체 최대 2건, 한 국가 최대 50%(5건). 국내·해외 60:40 은 **적용하지 않음**(주요 뉴스 전용).
4. 기준을 넘는 글이 모자라면 **채우지 않고** `shortfall` 에 남깁니다. 화면 상단에 "주제 n/6 · 시야 넓히기 n/4" 로 보입니다.
5. 과학·전기 탭 기사도 후보이며, 테마 기준으로 다시 고릅니다.

## 후보 보관

- `data/state/theme_candidates.json`: 최근 **28일** 후보만 따로 보관(Actions 캐시). 일반 뉴스 보관(3일)은 늘리지 않습니다.
  주제 개념이 하나라도 있거나, 테마·과학 섹션이거나, 연구·전문 출처인 기사를 넣습니다. 보관 항목은 기사 기록(제목·링크·매체·시각 등)뿐입니다.
- 과거 4주 기사를 모두 확보했다고 가정하지 않습니다. `theme.json` 의 `coverage` 에 보관 시작 시각과 **실제로 확보한 가장 오래된 후보**를,
  `topics` 에 주제별 후보 수·기준 통과 수·가장 오래된 후보 날짜·부족 여부를 남깁니다.
- 테마 전용 피드는 OPML `section="theme"` 이며 주요 뉴스·과학 탭 순위에 섞이지 않습니다.
- 이전 이름(`taste`) 호환: 설정의 `interest` 계열 키, 후보 보관소 `taste_candidates.json`, 아카이브의 `section="taste"`,
  브라우저에 저장된 탭 값 `taste` 는 읽을 때 새 이름으로 바꿉니다.

## 화면

카드: 원문 제목(원출처 직접 링크) · 매체/기관 · 발행일 · 태그 약 3개 · '주제/시야 넓히기' 표시.
**자동 번역·AI 요약·해설은 넣지 않습니다.** 주제 선택: 전체 / 주제 / 시야 넓히기 / 개별 주제. 선정 이유는 `theme.json` 의 `review` 에만 있고 화면에는 표시하지 않습니다.

## 5단계(AI) 검토 항목

규칙으로는 한계가 분명해 AI 가 도움이 될 수 있는 부분입니다. 비용과 출처 이용 조건(현재 AI 허용 출처 0곳)을 확인한 뒤 적용 여부를 정합니다.

1. **실제 깊이 판정**: 제목·RSS 요약만으로는 원인·구조·제도를 '구체적으로' 설명하는지 알 수 없습니다(현재 `판단 불가` 다수).
2. **'잠깐 언급' 구분**: 주제 낱말이 핵심인지 곁가지인지는 본문 맥락이 필요합니다.
3. **홍보성·협찬성 판별**: 표기 없는 기업 보도자료(예: '…기술 공유', '…와 협력')는 규칙으로 걸러지지 않습니다.
4. **분야 연결의 실제 여부**: 낱말이 함께 나오는 것과 글이 두 분야의 연결을 설명하는 것은 다릅니다.
5. **'새로운 질문' 여부**: 물음표·질문 표기 이상의 판단.
6. **추상적 제목의 에세이 분류**: 제목에 주제어가 없는 글은 주제 기사로 분류되지 못하고 시야 넓히기로만 갈 수 있습니다.

AI 를 쓰더라도 입력에 없는 사실을 만들지 않도록, 판단 결과만 받고 화면에는 요약·해설을 넣지 않는 것을 기본으로 합니다.
